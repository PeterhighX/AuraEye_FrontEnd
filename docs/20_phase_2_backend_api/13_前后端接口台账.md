# AuraEye 前后端接口台账

更新时间：2026-08-11  
维护范围：`MakeupChat` 前端与 AuraEye NestJS API 运行时契约。  
事实优先级：NestJS Controller/DTO/Service > Swift 实际调用 > OpenAPI > 历史执行文档。

## 维护规则

每次前端或后端完成接口相关工作并准备提交时，必须同步更新接口状态、字段、鉴权、状态码、对应代码位置和验证结果。未接入、废弃或仅规划的接口不得写成已可用。

状态含义：`已接入并匹配`、`后端可用但未接入`、`前端遗留`、`契约待同步`、`待开发`。

## 公共基线

- Base URL：`https://api-dev.peterhigh.xyz/v1`，Endpoint 常量不再包含 `/v1`。
- 成功 JSON：`{ "request_id": "...", "data": { ... } }`。
- 登录、刷新、退出、账号信息成功状态为 `200`；创建视觉任务为 `202`。
- 认证接口使用 JSON；视觉任务使用 `multipart/form-data`，文件字段为 `image`。
- 鉴权请求使用 `Authorization: Bearer <access_token>`；创建视觉任务还携带 `Idempotency-Key`。
- Bearer 请求首次收到 `401` 时，客户端只刷新一次并重放一次，不记录 token。

## Release demo 联调约束

- Release 必须包含 `DemoFixtures` 文件夹、manifest 和四张 canonical JPEG；不得通过 `EXCLUDED_SOURCE_FILE_NAMES` 排除。
- `fixed_demo` 完全由 `/auth/me` 或登录响应的 `features.gallery_mode` 判断，不检查用户名。
- `fixed_demo` 的用户档案、快速开始、档案详情和化妆品识别入口不显示相机，只进入固定演示相册。
- 固定相册首次建档保存原始图片字节；重新分析从本地文件读取相同 `Data` 与 MIME，不经过 `UIImage` 重编码。
- 固定 demo 的旧档案若不是 canonical 人脸原图，不提交视觉任务，提示重新从演示相册选择。
- Release 构建阶段禁止 `AURAEYE_ENABLE_LOCAL_AUTH_STUB` 出现在 `SWIFT_ACTIVE_COMPILATION_CONDITIONS` 或 `OTHER_SWIFT_FLAGS`。
- 本轮未修改后端服务、账号权限、Feature 字段或 `/vision/jobs` 公共请求字段。

本节记录 Swift 已实现的客户端调用；后端接口正在并行开发，当前尚未完成联调。演示身份只取 `account_mode=demo`，构建身份由每次 Xcode build 写入 App Bundle 的 `AuraEyeDemoBuildID.txt`。

| 路由和方法 | Swift 请求与用途 | 状态 |
| --- | --- | --- |
| `POST /demo/runs/open` | Bearer、`Idempotency-Key`；JSON `request_id, build_id`；登录后打开或恢复同一构建轮次，不带 run 头 | 契约待同步；Swift 已接入，后端待联调 |
| `GET /demo/runs/{run_id}` | Bearer；前台恢复和本轮写操作后刷新 `completed_steps, next_step, active_plan_id, active_session_id` | 契约待同步；Swift 已接入，后端待联调 |
| `POST /vision/jobs`、`POST /cosmetics`、`POST /makeup/plans`、`POST /makeup/sessions`、`POST /makeup/sessions/{id}/actions`、`POST /makeup/sessions/{id}/complete` | 仅 demo 当前轮次额外带 `X-AuraEye-Demo-Run-ID`；原 `request_id`/`event_id` 和幂等键保留，401 重放同一请求头 | 契约待同步；Swift 已接入，后端待联调 |

所有 GET、签到、天气、聊天、知识事件及普通账号请求不带 run 头。前端不读取本地结果 seed JSON；四张固定原图及 manifest 继续打包，视觉结果和图片仍由受保护的服务端接口返回。`DEMO_RUN_STALE` 触发重新 open 当前 build，不重发旧 Job。

## 当前阻断项与遗留项

1. Release API Base URL 已配置为 `/v1` 基地址，Archive 后仍需复核最终 App Info.plist。
2. `/chat/messages`、`/makeup/generate`、`/makeup/recommendations` 尚无已确认 NestJS Controller，不得作为已上线接口调用。
3. Release 真机三条人脸流程必须在安装新的 Archive 后执行，记录脱敏 request_id，不记录 token、密码或图片内容。
